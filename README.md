# 🏠 Real Estate Investment Advisor

## 📌 Project Overview

The **Real Estate Investment Advisor** is a Machine Learning based web application developed using Python and Streamlit.  
The project helps users analyze real estate investment opportunities by predicting:

- ✅ Whether a property is a **Good Investment**
- 📈 Estimated **Future Property Price after 5 Years**

The application combines **Machine Learning, Data Analytics, Feature Engineering, and Interactive Visualization** to provide intelligent property insights.

---

# 🚀 Features

- Investment Classification
- Future Price Prediction
- Interactive Streamlit Dashboard
- Dynamic EDA Charts
- Property Insights & Analytics
- Feature Engineering
- Visual Data Analysis
- User-Friendly Interface

---

# 🧠 Machine Learning Concepts Used

## 1. Classification
Used to predict whether a property is a good investment or not.

### Model Used
- Random Forest Classifier

---

## 2. Regression
Used to estimate the future property price after 5 years.

### Model Used
- Linear Regression
